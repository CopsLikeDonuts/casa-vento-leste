# Демо-сайт гестхауса (шаблон)

Вымышленный гестхаус «Casa Vento Leste» в Фуншале. Это и пример для рассылки, и шаблон для настоящих клиентов.

## Запуск

```bash
npm install
npm run build     # статическая сборка в out/
npm run preview   # http://localhost:4173/pt/
```

Для разработки: `npm run dev`, потом открыть http://localhost:3000/pt/.

## Как сделать сайт для клиента

1. Поменять `site.config.ts`: название, заголовок, цвета (`colors`), тексты на трёх языках, номера с цветом двери (`rooms[].door`), цены, контакты, координаты, FAQ.
2. Положить фото в `public/photos/` в трёх размерах WebP: `name.webp` (1600 px), `name-800.webp`, `name-480.webp`. В конфиге указать `photo('name', ширина, высота)` в `hero.image`, `rooms[].image` и `photos`. Без фото рисуются иллюстрации.
3. Поставить `demo: false`. Это убирает плашку демо и `noindex`.
4. Указать номер WhatsApp в `contact.whatsapp`. С пустым номером кнопка показывает пояснение.
5. Заменить фейковую занятость (`lib/availability.ts`) на данные channel manager клиента, а подтверждение брони отправлять ему на email или в WhatsApp. В демо этого нет.

## Что внутри

- Next.js 16, статический экспорт, TypeScript, Tailwind 4. Тяжёлых библиотек нет.
- Языки: `/pt/`, `/en/`, `/de/`. Корень `/` перекидывает на язык браузера, по умолчанию PT.
- Бронирование целиком на клиенте: даты, номер, данные гостя, итог со сравнением цены с Booking.com, подтверждение. Ничего никуда не отправляется.
- UI-строки лежат в `lib/i18n.ts`, всё про конкретный гестхаус в `site.config.ts`.
